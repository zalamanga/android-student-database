# Catatan sumber

Source utama berasal dari folder lokal AplikasiDatabase. Perapihan mempertahankan namespace com.rapik.example.aplikasidatabase, label aplikasi, layout, ikon, dan field siswa. Alur CRUD, penanganan input/resource, sesi, dan penyimpanan password diperbaiki pada salinan publik; sumber asli tidak diubah.

Tidak ditemukan LICENSE proyek atau metadata Git yang menetapkan upstream. Catatan ini tidak memberikan lisensi baru untuk kode atau aset asal. Gradle Wrapper membawa header Apache 2.0 sendiri; dependency AndroidX, Material Components, dan JUnit mengikuti lisensi masing-masing.
